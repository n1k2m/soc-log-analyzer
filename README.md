# SOC Log Analyzer

A detection engineering tool that parses Apache access logs, applies SOC-style detection rules, integrates Threat Intelligence data, and produces prioritized alerts with a visual activity report.

Built as a portfolio project demonstrating SOC analyst and Python automation skills.

---

## What it detects

| Rule | Severity | Description |
|---|---|---|
| Brute Force | HIGH | 5+ failed logins (401) from one IP |
| Blacklist Hit | HIGH | Requests from IPs in TI feed |
| High Traffic | MEDIUM | Single IP exceeds request threshold |
| Traffic Spike | MEDIUM | Minute bucket 3× above average |
| Correlation | CRITICAL | Brute force + blacklist hit from same IP |

```

```

## Quickstart

```bash
git clone https://github.com/1tnv/soc-log-analyzer
cd soc-log-analyzer

pip install -r requirements.txt

python main.py
```

Results appear in `output/`:
- `report.json` — all alerts sorted by severity
- `activity.png` — requests-per-minute chart
- `analyzer.log` — run log

---

## Configuration

Edit `config.py` to tune detection thresholds:

```python
FAILED_LOGIN_THRESHOLD = 5   # 401 responses before brute force alert
HIGH_REQUEST_THRESHOLD = 200 # requests/IP before high traffic alert
SPIKE_MULTIPLIER = 3         # how many × average = spike
```

**Threat Intelligence:** the tool checks `data/blacklist_cache.json` first. To use live AbuseIPDB data, set `TI_API_KEY` in `config.py`. The result is cached automatically.
